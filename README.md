# Task Tracker

A full-stack task management app with productivity tracking.

## Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: NestJS, TypeScript, MySQL, TypeORM
- **Package Manager**: npm workspaces

## Features

- Task management with subtasks and comments
- Productivity dashboard and analytics
- User authentication
- Activity tracking

## Getting Started

### Prerequisites
- Node.js 18+
- MySQL 8+

### Installation

```bash
npm install
```

### Setup

1. Create MySQL database
2. Update `backend/.env` with database credentials
3. Run migrations: `npm run migration:run` (in backend folder)

### Running

```bash
npm run dev
```

- Frontend: http://localhost:3000
- Backend: http://localhost:4000
